Aún me preguntan dónde está el PDF. No hay ninguno, y es una decisión, no un
descuido. Tras veinte años redactando requisitos en el software financiero
—primero analista de negocio, después product owner— apliqué la misma disciplina
a mi propio CV: entender primero quién lo lee y para qué, y elegir después el
soporte.

## Un CV no se presenta: responde

### El PDF llama a la puerta; la web espera

Un PDF se presenta: se envía, llama a una puerta y se suma a un centenar de
adjuntos en un buzón. Una web no se presenta. Espera: al reclutador que oyó tu
nombre, al antiguo compañero que quiere citarte, a quien pinchó en un enlace.
Cada visita llega con una pregunta precisa. El trabajo de la página es
responderla en diez segundos.

### Treinta segundos, no dos páginas

He entrevistado a suficiente gente para saber cómo se lee un CV: en diagonal, en
treinta segundos, buscando una respuesta exacta que justifique una decisión. Un
documento congelado contesta a todas las preguntas con la misma hoja A4. Una
página web puede llevar directamente a la respuesta.

## Lo que aporta la web

### Enlaces profundos

Cada sección de esta web tiene su propia dirección. Cuando alguien me pregunta
si he dirigido alguna vez una migración de core banking, no mando un documento
diciendo «mira en la página dos»: mando un enlace que se abre exactamente en esa
experiencia. El enlace es la respuesta.

### Idiomas, no traducciones

Desde Chengdu trabajo en varios idiomas, y esta web hace lo mismo. Cada versión
está escrita para su lector: un CV multilingüe no es un documento traducido
siete veces, sino la misma trayectoria bien contada siete veces. Un PDF
multilingüe sería un archivo zip; aquí cada idioma tiene su página, indexada y
compartible.

### La medida

La web mide lo que un documento se limita a imprimir. Aquí el texto se mide
antes de mostrarse: el tamaño de los titulares, el corte de las líneas y la
anchura de cada columna se ajustan a la pantalla del lector. Un PDF impone su
hoja A4 a ordenadores y móviles por igual; una página web se adapta a quien la
lee.

Veinte años de software financiero me enseñaron que un buen documento responde a
la pregunta que se le hace, en lugar de preverlas todas. Esta web es mi CV
porque hace exactamente eso: espera tu pregunta.
