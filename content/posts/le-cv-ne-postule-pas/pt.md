Perguntam-me às vezes onde está o PDF. Não existe, e isso é uma decisão, não um
esquecimento. Depois de vinte anos a escrever requisitos no software financeiro
— primeiro analista de negócio, depois product owner — apliquei a mesma
disciplina ao meu próprio CV: perceber primeiro quem o lê e porquê, escolher o
suporte depois.

## Um CV não se candidata — responde

### O PDF bate à porta, o sítio espera

Um PDF candidata-se: envia-se, bate a uma porta, junta-se a uma centena de
anexos numa caixa de correio. Um sítio não se candidata. Espera — pelo
recrutador que ouviu o seu nome, pelo antigo colega que o quer citar, por quem
clicou numa ligação. Cada visita chega com uma pergunta precisa: uma experiência
a confirmar, um contacto a pedir. O trabalho da página é responder em dez
segundos.

### Trinta segundos, não duas páginas

Entrevistei gente suficiente para saber como se lê um CV: na diagonal, em trinta
segundos, à procura de uma resposta exacta que justifique uma acção — marcar uma
entrevista ou passar ao seguinte. Um documento parado responde a todas as
perguntas com a mesma folha A4. Uma página web pode conduzir directamente à
resposta.

## O que a web acrescenta

### Ligações profundas

Cada secção deste sítio tem o seu próprio endereço. Quando me perguntam se já
dirigi uma migração de core banking, não envio um documento com um «veja a
página dois»: envio uma ligação que abre exactamente nessa experiência. A
ligação é a resposta.

### Línguas, não traduções

A partir de Chengdu trabalho em várias línguas, e este sítio faz o mesmo. Cada
versão foi escrita para o seu leitor: um CV multilingue não é um documento
traduzido sete vezes, é o mesmo percurso bem contado sete vezes. Um PDF
multilingue seria um ficheiro zip; aqui cada língua tem a sua página,
referenciada e partilhável.

### A medição

A web mede aquilo que um documento se limita a imprimir. Aqui o texto é medido
antes de aparecer: o tamanho dos títulos, a quebra das linhas, a largura de cada
coluna ajustam-se ao ecrã do leitor. Um PDF impõe a sua folha A4 a todos os
ecrãs; uma página web ajusta-se a quem a lê.

Vinte anos de software financeiro ensinaram-me que um bom documento responde à
pergunta que lhe é feita, em vez de prever todas. De facto, é por isso que este
sítio é o meu CV: está à espera da sua pergunta.
